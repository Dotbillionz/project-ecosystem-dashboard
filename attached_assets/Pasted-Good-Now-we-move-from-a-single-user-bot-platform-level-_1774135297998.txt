# 🔁 STEP 4 — COPY TRADING ENGINE

This is the core.

```javascript id="copy1"
export async function copyTrade(trade) {

  for (const userId in users) {

    const user = users[userId];

    if (!user.copy) continue;

    // 📦 proportional allocation
    const userAmount = (user.balance / 10000) * trade.amount;

    console.log(`Executing copy trade for ${userId}`);

    // Simulated execution (or real via sub-accounts later)
    user.balance -= userAmount * trade.price;

    user.pnl += 0; // update later
  }
}
```
