# Project Ecosystem Dashboard

  **An interactive 9-project portfolio ecosystem with:**
  - SpotX TradeBot (EMA/RSI live trading)
  - Multi-user platform with Replit Auth
  - Per-user wallets, trade history, copy trading
  - Real-time crypto analytics
  - Role-based UI across all 9 projects

  Built with React + Vite + TypeScript + Express + PostgreSQL.
